## 4. 供应商与采购要点

- **ESP32-S3/P4**: 立创商城/Espressif 官方，批量价更低
- **LSM6DSV16X**: Mouser/DigiKey，需注意 breakout 版本 CS 必须拉高 3.3V 才走 I²C
- **Flex 2.2"**: 淘宝，一致性差需来料筛选
- **eSkin (Pro)**: 待选型，候选：导电浆/压阻/电容，需小批量试样测一致性 🔬
- **PCB**: 嘉立创打样，双手板 ≤100×100mm 5 元打样

## 5. 风险

- **Flex 一致性** (Lite): 老化/标定难 → NVS 校准 + 定期复校
- **eSkin 量产** (Pro): 当前为科研级，量产一致性 🔬 → 需供应链合作伙伴
- **ESP32-P4 供货**: 新品，备货风险 → 二供选 STM32H7
